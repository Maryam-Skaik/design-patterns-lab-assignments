## 📌 Overview

This repository contains the official assignments for the Design Patterns Lab course.
Each assignment is provided in a separate directory with its own full specification, requirements, and (where applicable) reference solution.

---

## 📂 Repository Structure

```text
Assignment-1/
Assignment-2/
```

Each folder contains:

* `README.md` → assignment specification and requirements
* `solution/` → reference implementation (if provided)

## 📘 Assignments

* Assignment 1 → Smart University Lab Resource Management System
* Assignment 2 → Adaptive Learning Management System (ALMS)

Detailed descriptions are available inside each assignment folder.

## 📎 Notes

* Each assignment is self-contained
* Follow instructions inside each assignment directory
* Solutions are intended for reference and evaluation
* Focus on clean design and correct use of design patterns

## 📄 Requirements
